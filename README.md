# How-I-Think

A Git-backed externalization of recurring reasoning patterns, mental models, and decision rules.

Start here:

- [Reasoning Kernel](./Topographical%20Speculative%20analysis%20of%20a%20sentient%20recursive%20learning%20engine%20with%20deep%20cross%20domain%20referencing%20Autopoiesis.md) — causal modeling, evidence handling, minimum sufficient understanding/commitment, analogy-as-simulation, ownership/dependency reasoning, and the operating loop.

This repository is not meant to freeze a personality into rules. It is meant to make useful cognitive structure inspectable, testable, transferable, and revisable.
